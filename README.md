# Gestão de Demandas - IPEM/RN

Sistema de controle e acompanhamento de demandas para o **IPEM/RN**, com foco inicial nas rotinas da **CORED**.

---

## 🚀 Como funciona?

1. Uma demanda é cadastrada (com data, descrição e destinatários).
2. Ela aparece em um quadro **Kanban**:
   - `Recebida` ➔ `Em triagem` ➔ `Em execução` ➔ `Em validação` ➔ `Respondida` ➔ `Encerrada`
3. O responsável pode dividir em tarefas usando **5W2H** e controlar prazos.
4. O checador confere a entrega antes de enviar a resposta final (via SEI).
