# Gestão de Demandas — IPEM/RN

Projeto para acompanhar demandas, responsáveis e prazos do Instituto de Pesos e Medidas do Rio Grande do Norte. O primeiro fluxo é o de demandas recebidas da CORED/Inmetro.

O acompanhamento será feito em um quadro Kanban. Cada demanda poderá ter tarefas, planejamento 5W2H, confirmação de ciência e registro da resposta. Os processos e documentos oficiais continuarão no SEI ou no sistema de origem.

## Situação atual

Levantamento de requisitos e protótipo de baixa fidelidade. A primeira tela apresenta as colunas do quadro; filtros e movimentação ainda não estão disponíveis.

Para visualizar, abra [prototipo/index.html](prototipo/index.html) no navegador após baixar o repositório.
