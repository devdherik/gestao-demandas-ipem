# Quadro Kanban

Abra `index.html` no navegador, sem instalar dependências.

Esta versão contém o cabeçalho, os campos de pesquisa e seis colunas. Os filtros estão desabilitados; cartões e movimentação serão adicionados nas próximas partes.

Os estilos ficam em `assets/css/kanban.css`. A divisão prevista para os próximos arquivos está em [Organização do protótipo](../docs/arquitetura-prototipo.md).
