# Protótipo Kanban

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Etapa atual

Estrutura visual em baixa fidelidade: cabeçalho, filtros e seis colunas. Os controles de pesquisa estão desabilitados porque seu comportamento será adicionado na próxima etapa. Não há cadastro, persistência ou movimentação nesta versão.

## Organização

O HTML define o conteúdo; o CSS fica em `assets/css/kanban.css`. JavaScript será adicionado em módulos quando os filtros e cartões entrarem no protótipo.

Referência: [organização do protótipo](../docs/arquitetura-prototipo.md).
