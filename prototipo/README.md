# Quadro Kanban

Abra `index.html` no navegador. Alterne Jaime, Rafaela, Flávia e Bruno para experimentar as permissões. Os exemplos são fictícios.

Combine os filtros e abra um cartão para consultar detalhes, confirmar ciência, planejar tarefas e registrar checagem. Arraste os cartões ou use o seletor de etapa. Só o destinatário original altera o executor e conclui providências; demandas de ciência encerram após todos confirmarem.

Os anexos são selecionados e removidos nos detalhes. Nada é enviado ou salvo: recarregar descarta dados e arquivos. As permissões são simuladas no navegador e precisarão de validação no servidor na aplicação real.

HTML, estilos e comportamento ficam separados em `index.html`, `assets/css/kanban.css` e `assets/js/kanban.js`.

Verificados em Node: sintaxe, movimentação, restrição de executor, ciência coletiva e filtros combinados. Revisão visual e interação com anexos no navegador permanecem pendentes. Os nomes das etapas e a exigência de aprovação pelo checador devem ser validados pela equipe.
